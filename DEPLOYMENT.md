# Medivise — Convex Migration & DL Health Prediction Setup

## Architecture Changes

| Layer | Before | After |
|-------|--------|-------|
| Backend | Node.js + Express + MongoDB | Convex (serverless) |
| Auth | Firebase + Express JWT | Firebase + Convex Auth |
| Database | MongoDB (Mongoose) | Convex (built-in) |
| DL Model | None (stubbed) | Python FastAPI + TensorFlow |
| AI Chat | Stub | Convex + (future LLM integration) |

## Prerequisites

- Node.js v18+
- Python 3.9+ (for ML service)
- Convex account (https://convex.de)
- Firebase project (already configured)

## Step 1 — Deploy Convex Backend

```bash
# Install Convex CLI
npm install -g convex

# Login to Convex
npx convex login

# Initialize Convex in the project
npx convex init

# Deploy the schema and functions
npx convex deploy

# Seed the medical database
npx convex run functions/seed.seedDatabase
```

After deployment, note your Convex deployment URL (e.g., `https://medivise-xyz.convex.cloud`).

## Step 2 — Configure Frontend

```bash
cd frontend

# Copy env example and fill in your Convex URL
cp .env.example .env
# Edit .env: set VITE_CONVEX_URL=https://your-deployment.convex.cloud

npm install
npm run dev
```

The frontend will run on http://localhost:5173.

## Step 3 — Run ML Service (Optional, for DL predictions)

```bash
cd ml

# Install Python dependencies
pip install -r requirements.txt

# Start the ML service
python serve.py
```

The ML service runs on http://localhost:8000. Set `ML_SERVICE_URL` in your Convex environment variables:

```bash
npx convex env set ML_SERVICE_URL http://localhost:8000
```

Or deploy the ML service separately and point Convex at the production URL.

## Step 4 — Train the DL Model (Optional)

The included `serve.py` uses a rule-based model. To train a real TensorFlow model:

```bash
cd ml
python train.py
```

This generates `ml/model/disease_model.h5` and `ml/model/metadata.json`.

## Key Features Added

1. **Convex backend** — Replaces Express + MongoDB. Serverless functions, real-time database, built-in auth.

2. **DL Health Prediction** — Python FastAPI service with rule-based model (easily swappable for TensorFlow). Takes symptoms + age + gender, returns predicted disease with confidence %.

3. **Medicine Advice** — Disease→medicine mappings with confidence scores, dosage, frequency, duration, and contraindications.

4. **Large Medical Dataset** — 100+ diseases, 120+ symptoms, 90+ medicines with weighted symptom-disease and disease-medicine relationships.

5. **Prediction UI** — New `/prediction` page + integrated prediction in consultation flow.

## Fixes Applied

- Doubled API path (`/api/api/patients`) → removed (Convex uses direct function calls)
- Wrong proxy port (5001 → 5000) → removed (no proxy needed)
- Missing MONGO_URI → removed (Convex handles data)
- Public patient routes → now require Convex authentication
- Hardcoded JWT secret → removed (Convex manages auth)
- Stub AI review → replaced with real DL prediction
- Hardcoded dashboard stats → now dynamic from Convex

## Deployment

**Frontend (Vercel):**
```bash
vercel --prod
```
Set `VITE_CONVEX_URL` in Vercel project settings.

**Backend (Convex):**
```bash
npx convex deploy
```

**ML Service:** Deploy separately (Render, Railway, Fly.io, etc.) and set `ML_SERVICE_URL` in Convex env.
